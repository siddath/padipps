# Nine DSA pattern reps

These package-free Java templates cover the pack's nine DSA problems. Every method throws a `TODO` exception. Implement them one at a time in an editor and narrate the pattern, invariant, trade-off, and complexity before coding.

Problems: Two Sum, Two Sum II, Subarray Sum Equals K, Longest Substring Without Repeating Characters, Daily Temperatures, Sliding Window Maximum, Number of Closed Islands, Is Graph Bipartite?, and Min Cost to Connect All Points.

## Prerequisites

- JDK 17 or newer
- No external libraries

## Compile and run

From this folder:

```bash
mkdir -p /tmp/study-lab-dsa-patterns
javac -d /tmp/study-lab-dsa-patterns *.java
java -cp /tmp/study-lab-dsa-patterns DsaPatternsTest
```

The untouched starter compiles and exits non-zero with nine named `TODO` failures. Keep the harness unchanged while you work; a later green run means only that these fixed examples pass.

## Return evidence

For each exercise, retain the exact command/output, source path, whether hints were used, final complexity, one edge-case trace, and your one-sentence invariant. Record the result only after reviewing it; the harness does not update your learning record.
