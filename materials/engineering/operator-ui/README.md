# Operator UI starter

Build an accessible, usable operator view for the fictional migration jobs in `jobs.json`. `index.html` is intentionally a semantic skeleton with no styling, behavior, or completed interface. Preserve ordinary HTML behavior before adding enhancement.

## Prerequisites

- A modern browser
- Python 3.10 or newer only if you want to serve the folder locally
- No package install, account, analytics, or backend

## Open locally

From the repository root:

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4174/`. The starter shows only headings and TODO placeholders. Use `rubric.md` and `manual-test-checklist.md` while you implement; neither is proof that a check was actually performed.

## Return evidence

Return the final file paths, browser/viewport tested, keyboard route, visible focus evidence, one retry/conflict walkthrough, any console errors, and the completed manual checklist. Keep screenshots and claims labelled by the environment in which they were observed.
